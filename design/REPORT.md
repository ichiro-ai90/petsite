# アイコン案（担当: ChatGPT gpt-5）

## 設計意図
最安ナビ用のUIに最適化した線画セット。24×24座標で統一し、顔アイコンで種別を揃え、塗りは「目」と「star-f」など最小限のみ。小サイズ(13〜18px)での視認性を最優先し、余白・見た目の線太さを光学的に合わせました。ロゴ(paw)は“ナビの矢印”を肉球内に入れて差別化。

## メモ
- 全アイコンはviewBox 0 0 24 24 を想定し、図形はおおむね3〜21に収めて端欠けを防止
- 線設定は親svgの stroke="currentColor" stroke-width="1.8" を前提。塗りは eyes と star-f、paw内の矢印のみ
- 動物はすべて“顔”で統一。目はr≈0.8〜0.9の塗り円で、小サイズでも潰れにくい
- 第一稿からの主な修正: 細かい口周りを削減/簡略化、耳や外形の位置を揃えて光学的サイズを統一、truckとshareを描き直して13pxでも読みやすく
- pawは大きい肉球をリング状にしつつ内側へ下向き三角(ナビ/価格決定の決めマーク)を追加してサイトの顔として差別化
- bird-fishは中央の仕切り+左ビーク/右尾ビレで、どちらかに寄らない中立構成
- reptileは横長頭部+斜めの目と最小限の二股舌で爬虫類性を示しつつ穏やかな表情に
